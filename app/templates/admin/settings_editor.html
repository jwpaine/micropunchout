{% if section == "posr" %}
  • extrinsic:<Name>: an <Extrinsic name="Name"> in the setup request
  • contact:name, contact:email: the endUser contact, else the first
  • shipto:address_id|name|street|city|state|postal_code|country
  • from:domain, from:identity: the buyer's From credential
  • value:<text>: a constant

Field names are yours (lowercase, dotted). The app uses user.external_id (required; identifies the shopper account), user.email, user.name and ship_to.id. Other fields are kept on the session and shopper account, and can be sent back in the cart with session:<field>.

Example: {"user.email": {"transform": ["lower"]}, "cost_center": {"from": ["extrinsic:CostCenter"], "required": true}, "account.id": {"from": ["shipto:address_id"], "map": {"1000": "C-10442"}}}

{% else %}
  • product:<field>: sku, name, description, unit_price, currency, uom, unspsc, manufacturer_name, manufacturer_part_id, lead_time_days
  • session:<field>: a field mapped from the setup request (Setup request tab)
  • value:<text>: a constant

Cart elements: item.description, item.supplier_part_aux_id, item.classification, item.classification_domain, item.manufacturer_part_id, item.manufacturer_name, item.lead_time, and item.extrinsic.<Name> for line-level extrinsics (left out when empty).

Example: {"item.supplier_part_aux_id": {"from": ["product:sku"]}, "item.extrinsic.CostCenter": {"from": ["session:cost_center"]}}
